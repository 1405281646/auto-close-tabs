# 自动关闭标签页

一个 Chromium 浏览器扩展（Chrome / Edge，Manifest V3）：配置哪些网页在打开指定时间后自动关闭标签页。

## 功能特性

- **规则配置**：按"域名 + 可选路径前缀"匹配网页，支持子域名
- **倒计时时长**：全局默认 20 秒，每条规则可单独覆盖
- **右键快捷添加**：在任意网页上右键，一键把当前页面加入规则
- **严格模式**：只要匹配规则，倒计时结束即无条件关闭标签页
- **安全保护**：窗口只剩最后一个标签页时跳过，不会自动关掉整个窗口
- **导航重置**：标签页跳转到新地址时按新 URL 重新评估倒计时
- **跨设备同步**：规则存于 `storage.sync`，登录同一浏览器账号即可同步

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择本项目文件夹（`auto-close-tab`）

## 使用

### 方式一：选项页配置

点击扩展图标 → 打开设置，或直接在 `chrome://extensions` 中点击本扩展的"详细信息"→"扩展程序选项"。

- **启用自动关闭**：总开关，关闭后所有规则暂停生效
- **全局默认倒计时**：未单独设置时长的规则使用此值（默认 20 秒）
- **规则列表**：查看和删除已有规则
- **添加规则**：填写域名（必填）和路径前缀（可选）、时长（可选）

### 方式二：右键菜单

在任意网页上右键 → "把当前页面加入自动关闭规则"，当前页面（域名 + 路径）即被加入规则。

## 规则匹配说明

| 输入 | 匹配范围 |
| --- | --- |
| `example.com` | `example.com` 及其所有子域名（`www.example.com`、`sub.example.com`）下的所有页面 |
| `example.com/watch` | 以 `https://example.com/watch` 开头的所有页面 |

- 匹配语义为"URL 以 域名+前缀 开头"
- 域名匹配包含子域名
- 仅匹配 `http` / `https` 页面

## 行为约定

- **严格模式**：倒计时结束后无条件关闭，不区分标签页是否激活、是否交互、是否固定、是否播放音频
- **末位标签页**：窗口只剩最后一个标签页时跳过不关闭
- **导航重置**：标签页 URL 变化时取消旧倒计时，按新 URL 重新评估

## 项目结构

```
auto-close-tab/
├── manifest.json        # MV3 清单
├── background.js        # 后台 service worker：规则匹配、倒计时、右键菜单
├── options.html         # 选项页
├── options.js
├── options.css
├── icons/               # 扩展图标（16/48/128）
├── CONTEXT.md           # 领域术语与设计决策
└── docs/adr/            # 架构决策记录
```

## 开发说明

- 倒计时使用 `chrome.alarms` 一次性闹钟实现（见 `docs/adr/0001-alarms-for-countdown.md`），保证 MV3 service worker 挂起后仍能可靠触发
- 权限：`tabs`（读取标签页 URL）、`storage`（规则存储）、`alarms`（倒计时）、`contextMenus`（右键菜单）
